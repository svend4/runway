# Чек-лист: PWA, совместимость устройств и релиз (FP-12)

Заготовка для людей: **ни одна строка ниже не выполнена** (колонка «Результат» пуста). В браузере и на устройствах эти проверки не запускались; всё, что сказано в `README.md` о PWA, проверено только в Node на заглушках
(`tests/pwa.test.mjs`, `tests/offline_inventory.test.mjs`). Заполняйте колонку «Результат» так: дата, браузер и версия, ОС, «прошла / не прошла» и одно предложение. Каждая неудача — запись в реестр рисков
(`../wiki/product/12-risks.md`) и, если нужно, баннер в продукте (REQ-157). Расчёт по введённым данным и правилам, не консультация.

Условие всех проверок PWA: страница открыта по `http://localhost/…` или `http://127.0.0.1:…` либо по HTTPS (по адресу в сети без HTTPS воркер не регистрируется — это задумано).
Адреса: XAMPP — `http://localhost/01/301/runway/prototype/demo/`; `node prototype/serve.mjs` — `http://localhost:8787/demo/`.
**Для замера `demo/coldstart.html` (P4) использовать Apache (XAMPP) или HTTPS-хост**: страница открывает приложение во вложенном окне, а `node serve.mjs` запрещает вложение страниц заголовком `frame-ancestors 'none'` (политика приложения не ослаблялась) — под ним страница через секунду сообщит об этом и числа не покажет (FP-48).

## 2. Совместимость устройств и браузеров (REQ-157)

Целевой набор: не менее двух версий iOS Safari, Android Chrome, настольный браузер. Для каждой пары «устройство × возможность» — «да / нет / частично», версия и дата.

Страницы для заполнения таблицы (FP-23; **на устройствах не запускались — замеры и проверки делают люди**, FP-40): `demo/compat.html` («Проверить это устройство») определяет наличие IndexedDB (с пробной записью), `persist()`, Web Locks, сервис-воркера, Worker, BroadcastChannel и File System Access и выводит готовую строку этой таблицы; столбцы «Установка PWA» (P5), «Офлайн» (P4) и «Воркер импорта» (P13) страница определить не может — они помечены «вручную». `demo/coldstart.html` даёт время до «Обзора» для столбца «Офлайн (P4)» (только через Apache или HTTPS-хост, не через `node serve.mjs`). `demo/bench.html` даёт p50 и p95 пересчёта на устройстве: запись вставляется в массив `devices` файла `../_ops/bench.json` (поле `device` — строка браузера). Страницы открываются по тому же адресу, что и приложение (рядом с `index.html`).
