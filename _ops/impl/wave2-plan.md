# План волны 2 и предварительные решения (2026-10-09)

Волна 2 — три пакета из [анализа реализации](../../wiki/product/18-implementation-gap-analysis.md): FP-10 (мастер «Старт», калькулятор v0, метрики на устройстве), FP-11 (сверка план↔факт, качество прогноза, вероятностная полоса по согласию), FP-12 (PWA, Worker, воспроизводимая сборка, замеры, мутации, фаззинг). Машиночитаемый бэклог — `_ops/gap/backlog.json` (поля `scope`, `acceptance`, `new_files`, `touched_files`). Порядок: FP-10 → FP-11 → FP-12 (FP-12 зависит от FP-10 и должен знать окончательный список файлов оболочки). Агенты работают строго по одному (машина с 7,8 ГБ ОЗУ), после каждого — независимая состязательная проверка и исправление дефектов.

Владелец 2026-10-09 ответил «Да, продолжение вместе с вашими рекомендациями»: ниже **предварительные решения координатора** по пяти открытым вопросам из страницы 18. Они обратимы и помечены в коде и документах словом «предварительно»; владелец может заменить любое из них.

|---|---|---|---|

## Общие правила для агентов волны 2

1. Только аддитивно; общие файлы (`app.mjs`, `ext.mjs`, `i18n.mjs`, `index.html`, `style.css`, `serve.mjs`) правит текущий пакет минимально и перечисляет правки.
2. Безопасность интерфейса: CSP `script-src 'self'; style-src 'self'`, без `innerHTML`, inline-стилей, обработчиков-строк, внешних адресов, `eval`; текст пользователя — только `textContent`.
3. RU и EN вместе; запрещённые формулировки (`lint_vocab`) не писать; налоговых и финансовых советов нет.
4. Тесты — по одному файлу: `node --test --test-timeout=240000 --test-concurrency=1 tests/<файл>.test.mjs`; никаких фоновых процессов и серверов (сервер для проверки — только если пакет требует и сразу гасится).
5. `STATE.md`, `wiki/log.md`, `wiki/index.md` — только координатор.
6. Браузер агентам не запускать; ручной проход в браузере делает координатор после волны.

## Что считается готовым

Приёмка — критерии пакета из `backlog.json` + независимая проверка (`accept`) + сквозной последовательный прогон всех файлов тестов + `lint`, `lint_vocab`, `additive_check` + проход в браузере (координатор).
