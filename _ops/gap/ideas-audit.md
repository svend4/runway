## Что реально делает демо (основа вердиктов)

- `demo/app.mjs` импортирует из движка только: `analyze`, `narrowest_point`, `answer_q1`, `explain_narrowest`, `default_sts_horizon`, `safe_to_spend`, `sts_breakdown`, `list_waves_ex`, `next_income_day`, `reserve_open`, даты и деньги, `make_tool_ctx`, `run_tool`, `call_ref`, `cause_class_of`, `a0_answer`, `render_value`, `LABELS` (строки 14–21). Поиск по `demo/` и `cli.mjs` слов `montecarlo|run_paths|backtest|hledger|export_csv|dry_run|match_plan|wilson|prepay|reanchor|gross_pay|rule_age|buffer_hint|runway_days|unlogged|serviceWorker|webmanifest|indexedDB|wave_overrides|stale_status` даёт 0 вхождений. Всё это живёт только в движке и тестах.
- Экраны (`VIEWS`): Обзор, Купить, Волны, Резервы, Сценарии, Лента, Ассистент, Данные. Данные пользователя в демо вводятся единственным способом: загрузка JSON состояния (`import_file`, лимит 5 МБ). Форм ввода фактов, правил, часов, буфера, курса, якоря нет; хранилище — только `localStorage` для языка и темы (`pref_set`).
- Сценарии в UI строит `scenario_ops`: только `delay_income` (+7/+14/+21/+30 дней), `add_purchase` и сохранённые `ws.scenarios`; движок умеет ещё `shift_flow`, `set_amount`, `remove_flow`, `add_flow`, `fx_shock` (`engine/timeline.mjs`, `apply_scenario`, строки 524–603), операция `hours` отвергается (`op_not_in_v1`).
- В движке уже есть то, чего решения каталога требовали только на v1.1/v2: Монте-Карло (`montecarlo.mjs`), калибровка и бэктест (`calibration.mjs`, `backtest.mjs`), `import_hledger`, график аннуитета, `reanchor`, `prepay`, `known_at` в `rule_at`, A1–A3 порты (`verifier.mjs` `answer_question`, `payload_for`).

## Как читать таблицу

| Метка статуса | Смысл |
|---|---|
| **реализовано** | есть код и тест/доказательство в рамках содержания идеи (для движковых идей — движок; для идей про экран — демо) |
| **частично** | есть часть; в ячейке указано, чего нет (часто «движок есть, демо нет») |
| **нет** | не найдено; указано, что искал |
| **не код** | процессное, бизнес- или документационное требование |
| **слито / отклонено** | по решению каталога кода не требуется |

Пути — относительно `C:\xampp\htdocs\01\301\runway\prototype\`. Усилие: S ≤ 0,5 дня, M 1–2 дня, L 3+ дня. Предложения аддитивны: новые файлы и экраны, существующие функции не переписываются. «Можно добавить сейчас?» — в ячейке предложения: если предложение есть, то да; «нельзя сейчас» с причиной — там, где нужно решение владельца или внешние данные.
