# Пакеты для людей (FP-27)

Здесь лежат шаблоны, протоколы и выгрузки для проверок, которые делают **люди**: юрист, интервьюер, наблюдатель с секундомером, добровольцы, владелец. Пакеты ничего не проверяют сами и **не заменяют** ни интервью, ни ревью, ни замеров: они только готовят почву и не дают цифрам и выводам появиться «мимо людей». Расчёт по введённым данным и правилам, не консультация.

## Что остаётся за людьми

| Что | Кто | Условие готовности |
|---|---|---|
| Юридическое ревью формулировок | юрист (имя и юрисдикцию называет владелец) | заполненная запись ревью по шаблону из пакета; без неё публичная бета не открывается |
| 8–10 интервью | владелец или интервьюер | сводка по шаблону и запись `decision` |
| Проверка критериев остановки | владелец | записи `decision` в сроки; первая проверка рынка не позже 2027-01-02 |
| Замер на не менее чем 5 людях | наблюдатель | файлы метрик и листы наблюдателя, цифра записана инструментом (он отказывает при n < 5) |
| Не менее 10 журналов добровольцев | владелец и добровольцы | сначала ответ владельца по ADV-6 |
| Чек-лист совместимости на устройствах (REQ-157) | человек с устройствами | таблица `prototype/CHECKLIST-release.md` (раздел 2) заполнена с датами и версиями; выгрузка проверок — страница `demo/compat.html` (FP-23); нового документа пакет FP-27 для этого не добавляет |

Принято: публиковать цифру времени («за N минут», «N секунд на ввод») нельзя, пока её нет в реестре обещаний с уровнем `measured`, числом людей и датой. LICENSE пакет не создаёт: выбор лицензии — решение владельца (FP-46).
